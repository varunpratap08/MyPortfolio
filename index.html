About

Backend first, full stack when the product needs it.

At Volvrit I work across 20+ client projects. Most of my time goes into the parts users never see: API design, MongoDB schemas and indexes, Redis and BullMQ queues, Socket.IO channels, payment flows and security. I also build the admin dashboards and product screens in React.js and Next.js.

Recent work includes a cold-chain logistics platform with live GPS and temperature tracking, a QR/NFC smart identity product with masked calling, and a real-time multiplayer quiz engine. On my own time I built and launched a multi-tenant website builder with custom-domain publishing.

I deploy what I build on AWS EC2 with Nginx, PM2 and GitHub Actions, and I'm currently learning Docker, Kubernetes and Terraform.
